## 2. プロジェクト概要
### 2.1 背景

スイングトレードでは、多数の銘柄のチャートやテクニカル指標を日々確認する必要があり、投資判断に多くの時間を要する。

本プロジェクトでは、チャートから特徴量を抽出し、それらを総合的に評価・スコア化することで、有望な銘柄を効率的に抽出する分析支援ツールを開発する。

### 2.2 目的

スイングトレードの意思決定を支援することを目的とする。

チャート分析、テクニカル分析および特徴量評価を自動化することで、分析時間を短縮するとともに、一貫した基準による銘柄評価を実現する。

### 2.3 ゴール

プログラムを実行すると、東京証券取引所に上場する銘柄を対象に分析を実施し、スコアの高い推奨銘柄を抽出できること。
特徴量を定量化し、それらを組み合わせたスコアリングによって、再現性のある売買判断を支援できること。

また、各銘柄について以下の情報を確認できること。
- 総合スコア
- 買いまたは売りの判断理由
- 検出されたチャートパターン
- 算出された主な特徴量

### 2.4 対象ユーザー

本システムの対象ユーザーは開発者本人とする。

将来的には、他のスイングトレーダーでも利用できるよう、拡張性・保守性を考慮した設計とする。

## 3. システム概要

### 3.1 システム構成

本システムは、データ取得から分析、スコアリング、結果表示までを責務ごとに分離したモジュール構成とする。

システムは以下のモジュールで構成する。

- Data Collector
  - 株価・出来高・財務データ等の取得
- Feature Engine
  - テクニカル指標の算出
  - チャート特徴量の抽出
- Pattern Detector
  - 特徴量を利用したチャートパターン認識
- Score Engine
  - 特徴量およびパターン認識結果を基に総合評価を実施
  - 押し目、買い時、売り時の評価を行う
- Screener
  - 条件による銘柄の絞り込み
- Ranking
  - スコア順にランキングを生成
- Presentation
  - 分析結果をCLIまたはGUIへ出力

Presentation層を独立させることで、分析ロジックを変更することなくCLIからGUIへ移行できる構成とする。


### 3.2 システムで実現すること

- 東京証券取引所の銘柄データを取得する。
- テクニカル指標およびチャート特徴量を算出する。
- チャートパターンを認識する。
- 各銘柄を定量的に評価し、スコア化する。
- 買い候補・売り候補をランキング形式で表示する。
- 売買判断の根拠（特徴量・チャートパターン・評価理由）を提示する。
- 将来的なGUI化やバックテスト機能の追加に対応できるアーキテクチャとする。


### 3.3 対象外とすること

初期バージョン（MVP）では以下は対象外とする。

- 自動売買機能
- 証券会社とのAPI連携
- リアルタイムデータ配信
- AI・機械学習による売買予測
- スマートフォンアプリ対応

これらは将来の拡張機能として検討する。

## 4. 分析要件

### 4.1 売買スタイル

- 売買手法はスイングトレードとする。
- 保有期間の目安は数週間〜3か月とする。
- トレンドフォローを基本戦略とし、押し目買いおよび戻り売りを重視する。
- 売買判断はチャート分析を主体とし、ファンダメンタルズは補助的な判断材料として利用する。


### 4.2 分析対象

- 分析対象は東京証券取引所に上場する銘柄とする。
- スクリーニングにより流動性や売買条件を満たす銘柄へ絞り込んだ上で詳細分析を実施する。


### 4.3 分析フロー

1. 市場データを取得する。
2. スクリーニングにより分析対象銘柄を抽出する。
3. テクニカル指標およびチャート特徴量を算出する。
4. チャートパターンを認識する。
5. 特徴量およびパターン認識結果からスコアリングを実施する。
6. 買い候補・売り候補をランキング形式で出力する。


### 4.4 出力内容

分析結果として、少なくとも以下の情報を表示する。

- 銘柄コード
- 銘柄名
- 総合スコア
- 売買区分（買い候補・売り候補・監視）
- 売買判断の理由
- 検出されたチャートパターン
- 主要な特徴量

## 5. 機能要件

### 5.1 データ取得
- 株価データ（OHLCV）を取得できること。
- 財務データを取得できること。
- データをローカルへ保存・更新できること。
- 過去データを指定期間取得できること。


### 5.2 スクリーニング
- 流動性条件により銘柄を絞り込めること。
- 売買条件（株価、出来高等）により絞り込めること。
- 条件は設定ファイル等から変更可能であること。


### 5.3 テクニカル分析
- 移動平均線、出来高、RSI、MACD等のテクニカル指標を算出できること。
- 新しいテクニカル指標を容易に追加できること。


### 5.4 チャート特徴量抽出
- チャートから特徴量を抽出できること。
- 特徴量は数値として定量化できること。
- 特徴量は他モジュールから利用可能であること。


### 5.5 チャートパターン認識
- 特徴量を利用してチャートパターンを認識できること。
- ダブルボトム、ダブルトップ等の代表的なパターンに対応できること。
- 将来的に新しいパターンを追加できること。


### 5.6 スコアリング
- 特徴量およびチャートパターンから総合スコアを算出できること。
- 売買判断の根拠を出力できること。
- スコアリングルールを変更できること。


### 5.7 ランキング
- 総合スコア順にランキング表示できること。
- 買い候補・売り候補・監視銘柄を分類できること。


### 5.8 レポート表示
- CLIで分析結果を表示できること。
- 将来的にGUIへ切り替え可能な構成であること。
- 分析結果をファイルへ出力できること。
