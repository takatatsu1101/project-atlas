# MAAlignmentScore

## 1. 概要
- Feature ID：M001
- Feature名：MAAlignmentScore
- 日本語名：移動平均線配列スコア
- カテゴリ：Moving Average
- バージョン：0.1.0
- ステータス：Draft
- 優先度：P1

## 2. 目的
- 複数の移動平均線の配列状態を数値化する。
- 移動平均線同士の位置関係や整列状況を定量的に評価し、市場のトレンド構造を把握する。
- トレンドの安定性や継続性を評価するための基礎情報として利用する。
- Score Engineにおけるトレンド評価や押し目・ブレイクアウト評価の入力情報として利用する。

## 3. 前提条件
- 評価対象期間の価格データが取得可能であること。
- 評価対象とする複数期間の移動平均線が算出済みであること。
- 各移動平均線が比較可能な状態であること。

## 4. 入力
- 入力データ
  - OHLCVデータ
- 使用するテクニカル指標
  - 複数期間の移動平均線
- パラメータ
  - 評価対象とする移動平均線の種類および期間
  - 評価期間

## 5. 出力
- 型
  - 数値（Float）
- 値域
  - 正規化されたスコア
- 値の意味
  - 高い値：移動平均線の配列が整っており、秩序だった状態を示す。
  - 中間の値：一部の配列は整っているが、全体としては不安定な状態を示す。
  - 低い値：移動平均線の配列が乱れており、方向性が不明瞭な状態を示す。

## 6. アルゴリズム
- アルゴリズム概要
  - 複数の移動平均線の位置関係を評価し、配列の整列状況や秩序性を数値化する。
- 処理手順
  - 必要な移動平均線を取得する。
  - 各移動平均線の位置関係を評価する。
  - 配列全体の整列状況を評価する。
  - 評価結果をスコアとして正規化する。
- 算出式の概要
  - 移動平均線同士の位置関係および配列状態を総合的に評価し、単一のスコアへ変換する。
  - 詳細な計算式は設計書で定義する。
- 使用するパラメータ
  - 評価対象となる移動平均線
  - 正規化方法
- 備考
  - 本Featureは移動平均線の配列状態のみを評価する。
  - 売買判断やトレンド判定は行わない。

## 7. 判定基準
- 高評価となる条件
  - 移動平均線が秩序だった配列となっている。
  - 配列の整合性が高い。
- 低評価となる条件
  - 移動平均線の順序が乱れている。
  - 配列の一貫性が低い。
- 正規化方法
  - 他Featureと比較可能なスコアとなるよう正規化する。
  - 詳細は設計書で定義する。

## 8. 利用箇所
- 利用モジュール
  - Score Engine
- 利用目的
  - Trend Scoreの評価
  - Pullback Scoreの評価
  - Breakout Scoreの評価
  - 総合スコア算出時の入力特徴量

## 9. 例外処理
- データ不足時
  - 必要な価格データまたは移動平均線が算出できない場合は算出不可とする。
- 異常値
  - 入力データに異常が含まれる場合は適切に除外またはエラーとして扱う。
- エラー時の扱い
  - Feature Engineの例外処理方針に従う。

## 10. テスト観点
- 正常系
  - 移動平均線が整列したチャートで高いスコアとなること。
  - 移動平均線が乱れたチャートで低いスコアとなること。
- 境界値
  - 一部のみ整列しているケースで中程度のスコアとなること。
- 異常系
  - データ不足時に適切な例外処理が行われること。
  - 不正な入力データに対して適切に処理されること。
- 期待値（代表的な入力・出力例）
  - 強い上昇トレンドで整列した移動平均線：高スコア
  - レンジ相場で交差を繰り返す移動平均線：低スコア
  - 配列が形成途中の状態：中程度のスコア

## 11. 今後の拡張
- EMAなど複数種類の移動平均線への対応。
- 配列の安定性や継続期間を考慮した評価への拡張。
- 配列変化の速度や転換過程を評価対象へ追加。
- 長期・中期・短期トレンドごとのサブスコアへの対応。
