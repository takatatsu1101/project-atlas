# MomentumScore

## 1. 概要
- Feature ID：O001
- Feature名：MomentumScore
- 日本語名：モメンタムスコア
- カテゴリ：Oscillator
- バージョン：0.1.0
- ステータス：Draft
- 優先度：P2

## 2. 目的
- 価格変動の勢い（モメンタム）を数値化する。
- オシレーター系指標から市場参加者の売買エネルギーや価格変動の勢いを評価する。
- トレンドの継続性や勢いの変化を定量的に把握するための特徴量として利用する。
- Score Engineにおけるブレイクアウト評価、押し目評価、トレンド評価などの入力情報として利用する。

## 3. 前提条件
- 評価対象期間のOHLCVデータが取得可能であること。
- 利用するオシレーター系指標が算出可能であること。
- 評価に必要な十分な過去データが存在すること。

## 4. 入力
- 入力データ
  - OHLCVデータ
- 使用するテクニカル指標
  - オシレーター系指標（例：RSI、MACD、ROC、Stochastic）
- パラメータ
  - 利用するオシレーター系指標
  - 各指標の算出期間
  - 評価期間

## 5. 出力
- 型
  - 数値（Float）
- 値域
  - 正規化されたスコア
- 値の意味
  - 高い値：価格変動の勢いが強い状態
  - 中間の値：価格変動の勢いが中程度の状態
  - 低い値：価格変動の勢いが弱い、または減速している状態

## 6. アルゴリズム
- アルゴリズム概要
  - オシレーター系指標から価格変動の勢いを評価し、その状態を単一のスコアとして数値化する。
- 処理手順
  - 評価対象となるオシレーター系指標を算出する。
  - 各指標から価格変動の勢いを評価する。
  - 複数指標を総合的に評価し、MomentumScoreを算出する。
  - スコアを正規化し出力する。
- 算出式の概要
  - オシレーター系指標が示すモメンタムの状態を統合してスコア化する。
  - 詳細な算出方法、統合方法、重み付けは設計書で定義する。
- 使用するパラメータ
  - 使用するオシレーター系指標
  - 各指標の評価期間
  - 正規化方法
- 備考
  - 本Featureは価格変動の勢いのみを評価する。
  - 買われ過ぎ・売られ過ぎや売買タイミングの判定は行わない。
  - 投資判断はScore Engineが担当する。

## 7. 判定基準
- 高評価となる条件
  - オシレーター系指標が強いモメンタムを示している。
  - 複数指標が一貫して価格変動の勢いを示している。
- 低評価となる条件
  - モメンタムが弱い、または減速している。
  - 指標間で勢いが確認できない。
- 正規化方法
  - 他Featureと比較可能なスコアとなるよう正規化する。
  - 詳細な正規化方法は設計書で定義する。

## 8. 利用箇所
- 利用モジュール
  - Score Engine
- 利用目的
  - Trend Score
  - Pullback Score
  - Breakout Score
  - Reversal Score
  - Total Score

## 9. 例外処理
- データ不足時
  - 必要な期間の価格データが不足する場合は算出不可とする。
- 異常値
  - 入力データまたは指標値に異常がある場合は適切に除外またはエラーとして扱う。
- エラー時の扱い
  - Feature Engine全体の例外処理方針に従う。

## 10. テスト観点
- 正常系
  - 強い上昇・下降モメンタムで高いスコアとなること。
  - モメンタムが弱い相場で低いスコアとなること。
- 境界値
  - モメンタムが中立付近で中程度のスコアとなること。
- 異常系
  - データ不足時に適切な例外処理が行われること。
  - 異常な入力値に対して適切に処理されること。
- 期待値（代表的な入力・出力例）
  - 強い上昇トレンド初期：高スコア
  - 横ばい相場：中〜低スコア
  - トレンド終盤で勢いが減速：中程度のスコア

## 11. 今後の拡張
- 利用するオシレーター系指標の追加・変更に対応する。
- 市場環境に応じた指標の重み付けを導入する。
- モメンタムの加速・減速を評価対象へ追加する。
- 時間軸ごとのモメンタム評価への対応。
