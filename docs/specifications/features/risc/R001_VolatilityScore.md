# VolatilityScore

## 1. 概要
- Feature ID：R001
- Feature名：VolatilityScore
- 日本語名：ボラティリティスコア
- カテゴリ：Risk
- バージョン：0.1.0
- ステータス：Draft
- 優先度：P2

## 2. 目的
- 価格変動の大きさを数値化する。
- 銘柄固有の値動きの特性を定量的に評価する。
- 他FeatureやScore Engineにおけるリスク評価の基礎情報として利用する。

## 3. 前提条件
- 評価対象期間のOHLCVデータが取得可能であること。
- ボラティリティ指標を算出できる十分な過去データが存在すること。

## 4. 入力
- 入力データ
  - OHLCVデータ
- 使用するテクニカル指標
  - ボラティリティを表す指標（例：ATR、ヒストリカル・ボラティリティ）
- パラメータ
  - 利用する指標
  - 評価期間

## 5. 出力
- 型
  - 数値（Float）
- 値域
  - 正規化されたスコア
- 値の意味
  - 高い値：価格変動が大きい状態
  - 中間の値：価格変動が平均的な状態
  - 低い値：価格変動が小さい状態

## 6. アルゴリズム
- アルゴリズム概要
  - ボラティリティ指標から価格変動の大きさを評価し、単一のスコアとして数値化する。
- 処理手順
  - ボラティリティ指標を算出する。
  - 現在の価格変動の大きさを評価する。
  - スコアを正規化して出力する。
- 算出式の概要
  - ボラティリティ指標から価格変動の程度を評価する。詳細な計算方法は設計書で定義する。
- 使用するパラメータ
  - 利用するボラティリティ指標
  - 評価期間
  - 正規化方法
- 備考
  - 本Featureは価格変動の大きさのみを評価する。
  - エントリー可否やリスクの判断は行わない。

## 7. 判定基準
- 高評価となる条件
  - ボラティリティが高い状態。
- 低評価となる条件
  - ボラティリティが低い状態。
- 正規化方法
  - 他Featureと比較可能なスコアとなるよう正規化する。詳細は設計書で定義する。

## 8. 利用箇所
- 利用モジュール
  - Score Engine
- 利用目的
  - Risk Score
  - Breakout Score
  - Reversal Score

## 9. 例外処理
- データ不足時
  - 算出不可とする。
- 異常値
  - 異常データは除外またはエラーとして扱う。
- エラー時の扱い
  - Feature Engine共通の例外処理方針に従う。

## 10. テスト観点
- 正常系
  - 値動きの大きい銘柄で高スコアとなること。
  - 値動きの小さい銘柄で低スコアとなること。
- 境界値
  - 平均的なボラティリティで中程度のスコアとなること。
- 異常系
  - データ不足時に適切に処理されること。
- 期待値
  - 急騰・急落局面：高スコア
  - ボックス相場：低スコア

## 11. 今後の拡張
- 複数のボラティリティ指標への対応。
- 市場全体のボラティリティとの相対評価。
- 時系列でのボラティリティ変化率の評価。
