# EarningsQualityScore

## 1. 概要
- Feature ID：F005
- Feature名：EarningsQualityScore
- 日本語名：利益の質スコア
- カテゴリ：Fundamental
- バージョン：0.1.0
- ステータス：Draft
- 優先度：P3

## 2. 目的
- 企業が計上する利益の信頼性・持続性の状態を定量的に数値化する。
- 会計上の利益と実際のキャッシュ創出力との整合性を評価する。
- 他のFundamental Featureと組み合わせてFundamental Scoreを算出するための基礎情報として利用する。
- 投資判断は行わず、利益の質のみを評価対象とする。

## 3. 前提条件
- 財務諸表およびキャッシュフロー計算書のデータが取得可能であること。
- 評価対象期間の財務データが十分に存在すること。

## 4. 入力
- 入力データ
  - 財務諸表データ
  - キャッシュフロー計算書データ
- 使用する財務指標
  - 利益の質を表す指標（例：営業キャッシュフロー、フリーキャッシュフロー、営業CFと純利益の整合性、キャッシュコンバージョン）
- パラメータ
  - 利用する財務指標
  - 評価対象期間

## 5. 出力
- 型
  - 数値（Float）
- 値域
  - 正規化されたスコア
- 値の意味
  - 高い値：利益の質が高く、利益の信頼性・持続性が高い状態
  - 中間の値：利益の質が平均的な状態
  - 低い値：利益の質が低く、利益の信頼性に課題がある状態

## 6. アルゴリズム
- アルゴリズム概要
  - 利益とキャッシュフローの関係性、および利益の継続性を表す指標を総合的に評価し、利益の質を単一のスコアとして数値化する。
- 処理手順
  - 必要な財務・キャッシュフローデータを取得する。
  - 各指標から利益の質を評価する。
  - 評価結果を統合し、EarningsQualityScoreを算出する。
  - スコアを正規化して出力する。
- 算出式の概要
  - 各利益品質指標を統合してスコア化する。詳細な計算方法、重み付け、正規化方法は設計書で定義する。
- 使用するパラメータ
  - 利用する財務指標
  - 評価対象期間
  - 正規化方法
- 備考
  - 本Featureは利益の質のみを評価する。
  - 利益の大小や投資判断は評価対象としない。

## 7. 判定基準
- 高スコアとなる条件
  - 利益と営業キャッシュフローの整合性が高い状態。
  - 継続的に安定した利益創出が確認できる状態。
- 低スコアとなる条件
  - 利益とキャッシュフローの乖離が大きい状態。
  - 一時的要因への依存が大きい状態。
- 正規化方法
  - 他Featureと比較可能なスコアとなるよう正規化する。詳細は設計書で定義する。

## 8. 利用箇所
- 利用モジュール
  - Score Engine
- 利用目的
  - Fundamental Score
  - Total Score

## 9. 例外処理
- データ不足時
  - キャッシュフロー情報を含む必要データが不足する場合は算出不可とする。
- 異常値
  - 異常な財務データや算出不能な指標は除外またはエラーとして扱う。
- エラー時の扱い
  - Feature Engine共通の例外処理方針に従う。

## 10. テスト観点
- 正常系
  - 利益と営業キャッシュフローが安定している企業で高スコアとなること。
  - 利益とキャッシュフローの乖離が大きい企業で低スコアとなること。
- 境界値
  - 平均的な利益品質で中程度のスコアとなること。
- 異常系
  - キャッシュフローデータ不足時に適切に処理されること。
- 期待値
  - 利益・営業CFともに継続して増加：高スコア
  - 黒字だが営業CFが継続してマイナス：低スコア

## 11. 今後の拡張
- アクルーアル比率など利益品質指標への対応。
- 一時利益・特別損益を考慮した評価への対応。
- 複数年度の利益品質トレンドを考慮した評価への拡張。
- 業種ごとの利益品質評価基準への対応。
