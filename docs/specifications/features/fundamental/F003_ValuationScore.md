# ValuationScore

## 1. 概要
- Feature ID：F003
- Feature名：ValuationScore
- 日本語名：割安性スコア
- カテゴリ：Fundamental
- バージョン：0.1.0
- ステータス：Draft
- 優先度：P2

## 2. 目的
- 企業の市場評価（バリュエーション）の状態を定量的に数値化する。
- 株価と企業価値の関係から、相対的な割安性・割高性を評価する。
- 他のFundamental Featureと組み合わせてFundamental Scoreを算出するための基礎情報として利用する。
- 投資判断は行わず、企業のバリュエーションのみを評価対象とする。

## 3. 前提条件
- 株価データおよび財務データが取得可能であること。
- 評価対象となる財務指標が算出可能であること。

## 4. 入力
- 入力データ
  - 株価データ
  - 財務諸表データ
- 使用する財務指標
  - バリュエーションを表す指標（例：PER、PBR、EV/EBITDA、PSR）
- パラメータ
  - 利用する財務指標
  - 評価対象期間

## 5. 出力
- 型
  - 数値（Float）
- 値域
  - 正規化されたスコア
- 値の意味
  - 高い値：相対的に割安な状態
  - 中間の値：市場平均に近い評価状態
  - 低い値：相対的に割高な状態

## 6. アルゴリズム
- アルゴリズム概要
  - 複数のバリュエーション指標を総合的に評価し、市場評価の状態を単一のスコアとして数値化する。
- 処理手順
  - 必要な株価・財務指標を取得する。
  - 各バリュエーション指標を評価する。
  - 評価結果を統合し、ValuationScoreを算出する。
  - スコアを正規化して出力する。
- 算出式の概要
  - 各バリュエーション指標を統合してスコア化する。詳細な計算方法、重み付け、正規化方法は設計書で定義する。
- 使用するパラメータ
  - 利用する財務指標
  - 評価対象期間
  - 正規化方法
- 備考
  - 本Featureは市場評価の状態のみを評価する。
  - 割安だから買い、割高だから売りといった投資判断は行わない。

## 7. 判定基準
- 高スコアとなる条件
  - バリュエーション指標が総合的に割安な状態を示している。
- 低スコアとなる条件
  - バリュエーション指標が総合的に割高な状態を示している。
- 正規化方法
  - 他Featureと比較可能なスコアとなるよう正規化する。詳細は設計書で定義する。

## 8. 利用箇所
- 利用モジュール
  - Score Engine
- 利用目的
  - Fundamental Score
  - Total Score

## 9. 例外処理
- データ不足時
  - 算出不可とする。
- 異常値
  - 財務指標が算出不能または異常値の場合は除外またはエラーとして扱う。
- エラー時の扱い
  - Feature Engine共通の例外処理方針に従う。

## 10. テスト観点
- 正常系
  - 相対的に割安な企業で高スコアとなること。
  - 相対的に割高な企業で低スコアとなること。
- 境界値
  - 市場平均に近い評価で中程度のスコアとなること。
- 異常系
  - 財務データ不足時に適切に処理されること。
  - PER等が算出不能な場合に適切に処理されること。
- 期待値
  - PER・PBRともに低水準：高スコア
  - PER・PBRともに高水準：低スコア

## 11. 今後の拡張
- 業種ごとのバリュエーション基準への対応。
- 同業他社との相対評価への対応。
- ヒストリカルPER・PBRを考慮した評価への拡張。
- DCFや残余利益モデルなど高度な企業価値評価への対応。
